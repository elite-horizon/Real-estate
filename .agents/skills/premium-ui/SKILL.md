# Premium UI

Create an editorial luxury-property experience, not a generic dashboard or template.

- Use the repository tokens for navy, charcoal, ivory, and restrained gold; do not scatter literal brand colors through components.
- Build visual hierarchy through scale, spacing, typography, imagery, and composition before adding decoration.
- Vary section structure when the content purpose changes. Avoid long sequences of identical cards.
- Keep gold for emphasis and actions rather than large backgrounds or body text.
- Treat motion as feedback or spatial continuity. Respect reduced-motion preferences.
- Design mobile layouts deliberately; do not merely stack the desktop composition.
- Include visible focus, sufficient contrast, semantic structure, and useful image alternatives.
- Mark invented claims, inventory, pricing, and confirmations as demo content.

Before finishing, inspect the affected UI at mobile, tablet, and desktop widths and check hover, focus, empty, loading, and unavailable states.
